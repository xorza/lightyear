- On the fork's `main`, `lz4_decompression_respects_configured_size_cap` in `crates/transport/transport/src/packet/compression.rs` calls `lz4_flex::block::compress_prepend_size`, which the workspace's `lz4_flex` features (no `alloc`) do not provide. `cargo test -p lightyear_transport --all-features` and `cargo clippy -p lightyear_transport --all-targets --all-features` do not compile.
- `FragmentConstructor::new` allocates `received: vec![false; num_fragments]` from the `num_fragments` of the first fragment received, and nothing bounds that count, which a peer sends as a varint up to `u64::MAX`. One packet with a very large count makes the receiver allocate that much memory, and the process aborts when the allocation fails. The reassembly buffer is `num_fragments * fragment_size` bytes and has no bound for an uncompressed message either.
- A `RawServer`'s `ClientOf` link that becomes `Unlinked` gets `Disconnected` but is never despawned: only a `Disconnecting` `ClientOf` is despawned (`crates/connection/connection/src/server.rs`, `disconnect`). On an IO layer that does not despawn its own link entities, each lost peer leaves an entity on the server.
- `steady_state_networking_work_stays_within_allocation_budget` (`crates/tests/tests/allocation_regression.rs`) is flaky. With `WARMUP_FRAMES = 128`, the "message send/receive" window often records one more deallocation than allocations (for example 5525 against 5526), so `assert_eq!(active.allocations, active.deallocations)` fails. With 512 warmup frames it passes. The per-frame median budget check also fails about one run in six, as it did before the removals.
- `cargo test --workspace --all-features` turns on `lightyear_core/not_mock`, so `lightyear_core::time::Instant` reads the real clock in `lightyear_tests`. Then `test_predicted_remove_restored_on_rollback`, `test_completed_mutate_tick_rollback_preserves_later_confirmed_values`, `test_batched_confirmed_values_survive_older_rollback` and `test_prespawn_local_despawn_match` fail. They pass with `-p lightyear_tests --all-features`.
